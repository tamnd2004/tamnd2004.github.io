02 · Featured project

BRIDGE

Broadening Research Inquiry to Discover Gaps and Evidence
Try the live demo Repository

Know whether a research direction or a paper's code is worth the effort, before you spend it. An AI research assistant for literature reviews, citation checks and repo reproducibility checks, where every claim links to a verbatim quote verified against the source paper.

How a literature review runs
✋ you approve
01

Criteria

Your topic becomes weighted criteria, year range and exclusions. You edit them and see cost first.

02

Search

Semantic Scholar, OpenAlex and arXiv, with queries for each facet.

03

Screen

Every candidate is scored against every criterion, with a quote.

✋ you approve
04

Read & verify

An agent reads up to 100 papers in full. Code checks each quote really exists.

05

Write

The review is written only from checked evidence; every sentence is guarded.

Literature review

Plans, searches, screens and reads the field for you, then writes themes, research gaps and a comparison table.

You see: every citation opens the verbatim sentence

Citation check

Paste a draft, a chatbot answer or BibTeX. BRIDGE checks that each source exists and that each sentence matches it.

You see: what needs a second look, first

Repo reproducibility check

Compares a paper's GitHub repo with the paper by reading code, config and data only. It never runs it.

You see: gaps with file, line and paper passage
